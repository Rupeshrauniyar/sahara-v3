# Sahara
Sahara is a healthcare support platform that helps people connect with doctors, hospitals, blood donors, appointments, and AI-powered health guidance from one place.

## Features

- Role-based accounts for patients, doctors, hospitals, donors, and administrators
- Secure sign-up and sign-in system
- Personalized dashboard for each user role
- Appointment booking and doctor discovery
- Blood donation and blood-request support
- Hospital information and resource management
- AI health assistant for symptom guidance
- Responsive, modern healthcare-focused user interface
